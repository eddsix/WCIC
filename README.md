# What Can I Cook Today?

Android app for finding recipes from the ingredients available in the user's kitchen.

## Current version
V0.3

## Stack
- Kotlin
- Jetpack Compose
- Material 3
- Android SDK 36
- Min SDK 26

## Current features
- Onboarding
- Home
- My Kitchen
- Favorites
- Recipe search
- Match percentage
- Recipe detail
- Available and missing ingredients
- Local/offline recipe catalog

## Build
The repository includes a GitHub Actions workflow that builds the debug APK automatically.

Open **Actions** in GitHub, select **Build Android APK**, and download the generated artifact from a completed workflow run.
